# نظام طوارئ الغاز — الشركة الحديثة للغاز الطبيعي

مشروع React (Vite) مستقل بالكامل، لا يعتمد على أي خدمة خارجية —
كل البيانات (المستخدمين، البلاغات، المناطق، التنبيهات) تُخزَّن في
`localStorage` الخاص بمتصفح كل جهاز يفتح الموقع.

## ⚠️ طبيعة التخزين (مهم قبل الاستخدام)

البيانات محفوظة **محلياً في متصفح كل جهاز على حدة** — يعني لو فتحت
الموقع من جهازين مختلفين (موبايلك ولابتوبك مثلاً)، كل جهاز هيكون له
نسخته الخاصة من البيانات، ومفيش مزامنة تلقائية بينهم، لأن المشروع
مفيش فيه سيرفر/قاعدة بيانات مركزية حالياً.

لو محتاج كل المستخدمين (فريق الاستجابة، المدراء... إلخ) يشوفوا نفس
البلاغات لحظياً من أي جهاز، ده محتاج قاعدة بيانات حقيقية (زي Firebase
أو Supabase أو سيرفر Node.js + قاعدة بيانات) — قولّي لو عايز أجهزلك
النسخة دي بعدين.

## التشغيل محلياً

```bash
npm install
npm run dev
```

هيفتح على `http://localhost:5173`

## البناء للإنتاج

```bash
npm run build
npm run preview
```

## الرفع على Vercel

### الطريقة الأولى: من خلال GitHub
1. ارفع هذا المجلد كمستودع (repository) جديد على GitHub.
2. افتح [vercel.com](https://vercel.com) وسجّل دخول.
3. اضغط "Add New Project" واختر المستودع.
4. Vercel هيكتشف تلقائياً إنه مشروع Vite، سيب الإعدادات الافتراضية واضغط Deploy.

### الطريقة الثانية: من خلال سطر الأوامر مباشرة
```bash
npm install -g vercel
vercel login
vercel --prod
```

بعد الرفع هتاخد رابط جاهز (زي `your-project.vercel.app`) تقدر تشاركه
مع فريقك.

## أول تشغيل

أول ما حد يفتح الرابط ومفيش مستخدمين متسجلين، هتظهر شاشة "إعداد أولي"
لإنشاء حساب **سوبر أدمن** (اسم + كود دخول). بعدها أي حد يدخل بكود
الدخول بتاعه فقط.
